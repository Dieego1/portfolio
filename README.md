## 💻 Cómo ver localmente

No requiere servidor ni instalación.

**Opción 1 — Abrir directamente:**
```
Doble click → index.html
```

**Opción 2 — Desde terminal:**
```bash
# Windows
start index.html

# macOS
open index.html

# Linux
xdg-open index.html
```

**Opción 3 — Con servidor local** *(recomendado para el visor de CV/iframe PDF)*:
```bash
# Usando Python
python -m http.server 8080

# Usando Node.js
npx serve .

# Usando VS Code — instala la extensión "Live Server" y haz clic en "Go Live"
```

> ⚠️ Algunos navegadores bloquean iframes con rutas locales por seguridad.
> El visor PDF embebido funciona correctamente con cualquiera de las opciones de servidor arriba.
